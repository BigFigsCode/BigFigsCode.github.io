About Me

I’m a full-stack .NET developer and Computer Science graduate who builds web applications from the database to the browser. On the backend I work mainly with C#, ASP.NET Core, Entity Framework Core and SQL Server, and on the frontend with Angular and TypeScript.

My most recent project is an insurance policy management system. It has a REST API with JWT authentication, separate access for customers and administrators, and an Angular frontend, and it’s deployed on Azure. Building it gave me hands-on experience with API design, relational databases and security, and with taking an application from idea to live deployment.

Before moving into software development, I served in the United States Marine Corps. There I learned leadership, clear communication, and how to stay dependable under pressure as part of a team. I bring that same mindset to my work: learn quickly, solve problems methodically, and take ownership of what I build. I’m looking for a full-stack .NET developer role where I can contribute to real-world applications and keep growing.
