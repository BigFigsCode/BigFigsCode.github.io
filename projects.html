Project 1: Insurance Policy Management System

This is a full-stack web application for managing insurance products, policies and claims. The backend is a REST API built with ASP.NET Core, Entity Framework Core and SQL Server, and the frontend is built with Angular. Customers can register, browse insurance products, request coverage, and submit and track claims on their active policies. Administrators use a dashboard to activate policies, review and approve or deny claims, and manage the product catalog. Users log in with JWT authentication, and each role only sees what it is allowed to. The app is deployed on Azure. Here is a link to that project on github Click here!

Project 2: KVB Insurance (Team Project)

KVB Insurance is a full-stack insurance platform I built with a three-person team during Revature's .NET full-stack training. We migrated a monolithic application to ASP.NET Core Web API microservices with an Angular frontend, then revamped the UI and rebranded the site. The name KVB comes from our first initials. I owned the claims microservice, building claim submission and processing as an independent service, and added document uploads so customers can attach supporting files to their claims. I also designed the KVB Insurance logo used across the site. Built with C#, ASP.NET Core, Entity Framework Core, SQL Server, Angular and TypeScript. Project 3: Figgy Bank — Banking Management Application

Figgy Bank is a C#/.NET console-based banking application designed to simulate core customer and administrative banking workflows. The application allows customers to manage savings and checking accounts, perform deposits, withdrawals and transfers, review transaction history, request cheque books, and manage account credentials. Administrative functionality includes account management, password resets, account summaries, and cheque-book request approvals. Here is a link to that application. Click Here!
